# Deploying YouTube Watch Party to Render (Full WebSocket Support)

## Overview
Render supports persistent WebSockets out of the box, making it the ideal host for YouTube Party real-time room synchronization.

### Step-by-Step Instructions:
1. Create a new **Web Service** on Render.
2. Connect your GitHub repository `ritikyadav-io/Yotube-Watch-Party`.
3. Set Environment: **Node**
4. Build Command: `npm install && npm run build`
5. Start Command: `npm start`
6. Click **Create Web Service**. Your live Watch Party app with full WebSocket support is live!
